# 核心术语速查

这些解释用于建立索引，详细语义要回到对应章节、版本文档与源码。

## 任务与执行

| 术语 | 入门解释 | 常见混淆 |
| --- | --- | --- |
| task_struct | Linux 任务对象，保存执行与资源关联信息 | 不等同于一个完整进程的全部资源 |
| PID / TID / TGID | 用户可见标识与线程组关系，受 namespace 影响 | pthread_t 不是 Linux TID |
| runnable / running | 可以运行 / 当前正在 CPU 上执行 | 唤醒不保证立即运行 |
| waitqueue | 组织等待事件的任务 | 不自动保护所有共享数据 |
| completion | 完成通知的同步机制 | 不替代对象生命周期管理 |
| workqueue | 由工作线程执行排队工作 | 不是硬件队列的通用别名 |

## 内存与架构

| 术语 | 入门解释 | 常见混淆 |
| --- | --- | --- |
| VMA | 一段虚拟映射的范围与属性 | 不等于物理页或单个页表项 |
| page / folio | 物理内存管理中相关对象与抽象 | 不等于用户虚拟地址 |
| COW | 写入时按需要建立私有副本的机制 | fork 不要求立刻复制全部内存 |
| TLB | 地址转换结果的缓存 | 与数据 Cache 职责不同 |
| Cache coherence | 多个参与者对缓存数据一致性的协议 | 不替代程序同步与内存序 |
| EL | Arm 异常级框架 | 不等同于固定软件进程层级 |
| GIC | Arm 通用中断控制器 | 不负责执行用户任务调度策略 |
| PSCI | 电源状态协调的固件接口 | 不等同于 Linux CPU 调度器 |
| MMIO | 映射到地址空间的设备寄存器访问 | 不能按普通 RAM 随意访问 |

## 设备与平台

| 术语 | 入门解释 | 常见混淆 |
| --- | --- | --- |
| DMA | 设备参与内存数据传输的机制 | 不意味着任意 CPU 指针都可传给硬件 |
| dma_addr_t | 设备 DMA 视角的地址类型 | 不普遍等于 CPU 物理地址 |
| IOVA | I/O 虚拟地址，通常用于 IOMMU 转换场景 | 不保证跨设备域相同 |
| IOMMU | 设备侧地址转换与隔离相关单元 | 不自动保证数据已完成或缓存已同步 |
| DMA-BUF | 跨驱动/设备共享缓冲区框架 | 不自动等于零拷贝或处理完成 |
| dma-fence | 异步操作完成的同步对象 | 不提供数据存储本身 |
| DTS / DTB | 设备树源码 / 编译后的二进制表示 | DT 不直接执行初始化程序 |
| BSP | 芯片/板卡配套软件与适配集合 | 相同内核版本号不保证内容相同 |
| MPP | Rockchip Media Process Platform | 驱动媒体 task 不一定是 task_struct |
| SoC | 集成 CPU、内存接口与设备等的芯片 | 与 CPU 核、指令集、开发板不是同一层 |

想检验理解，选择两个相邻术语，例如 MMU/TLB 或 DMA-BUF/fence，分别写出它们解决的问题与不解决的问题，再找一个实验验证。

## 双架构与系统构建

| 术语 | 在实验中如何识别 |
| --- | --- |
| hart | RISC-V 硬件执行线程。查启动日志核实它与 Linux CPU 的对应关系。 |
| SBI / OpenSBI | 前者是监管者与底层环境的接口，后者是其实现之一。查本镜像的固件及所支持扩展。 |
| ABI | 程序与系统约定的数据布局和调用方式。核对 ELF、工具链和动态加载器。 |
| rootfs / PID 1 | 从内核命令行、实际挂载与 /proc/1/exe 找到当前用户空间。 |
| FreeRTOS 任务 | 用任务栈、调度及通知机制解释实时侧的事件。 |
