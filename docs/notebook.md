# 实验记录与答辩模板

把以下模板复制到自己的笔记中。公开提交前检查日志里的凭据、序列号、网络信息与未公开资料。

## 单次实验模板

```markdown
# 实验编号与标题
日期：
当前章节：

## 问题与预测
- 我想验证：
- 预计看到：
- 能推翻假设的现象：

## 环境
- 用户系统与 uname：
- 运行内核与配置：
- 源码 URL / 完整 SHA / 本地改动：
- 板型 / BSP / 固件 / DTB（如涉及）：
- 工具、输入与版本：

## 复现步骤
逐条命令、参数和输入，不省略准备条件。

## 原始证据
输出、trace、日志位置、采样时钟与可能噪声。

## 解释
- 核心对象与生命周期：
- 执行上下文与状态变化：
- 对应源码入口：
- 观测事实 / 源码推断 / 尚未确认：

## 反例
改变哪个条件，结果如何，说明什么。

## 结论边界与下一步
哪些结论可以迁移，哪些只适用于这个版本/平台。
```

## 提问时的最小信息

“我在 L02，预期 read 等待，但它返回空字节串；下面是打开顺序、代码、trace 和版本。我的解释是写端已全部关闭，这是否正确？”比“管道不对，怎么办”更容易得到准确帮助。

## 每周复盘

写下：本周最重要的三个因果关系、一个被实验推翻的想法、一个还没有证据的问题、下周的一个主实验。把“读了多少页”换成“能解释哪些现象”。

## 最终答辩模板

用 10 分钟说明：问题与复现（2 分钟）、对象与时序（4 分钟）、区分假设的实验（2 分钟）、结论边界与后续工作（2 分钟）。被追问时先区分已验证事实与推断，再回到证据。

完成标记只是提醒。真正的学习记录是你能复现、能解释、能被检验的实验。
